Troubleshooting and questions

The problems people run into most, what causes each one, and how to fix it.

#The launcher says files are missing, or to extract the ZIP

The launcher was opened from inside the ZIP, or the ZIP was only partly extracted. Close it, right-click the ZIP, choose Extract All…, and open the launcher from the extracted folder. Keep the launcher and the _system folder together. See Extract the ZIP before opening anything.

#The Mac will not open the launcher

  • "could not be executed because you do not have appropriate access privileges": open Terminal (Applications → Utilities), type chmod +x with a space after it, drag Free GST Billing - MAC into the Terminal window, press Enter, and open the file again. Downloads from v1.10.82 do not need this.
  • "cannot be opened because Apple cannot check it for malicious software" or "unidentified developer": the app is not signed by Apple. Hold Control, click Free GST Billing - MAC, choose Open, then Open again. Only the first time. Or use System Settings → Privacy & Security → Open Anyway.
  • "Node.js is not installed" or too old: install Node.js LTS from nodejs.org (or brew install node@20), then open the launcher again.

#Windows blocked the launcher

Click More info, then Run anyway. If it still will not open, right-click the launcher, choose Properties and tick Unblock. See "Windows protected your PC".

#The install stopped with an error

  • "Could not download Node.js" or "could not install the app's dependencies": the first install needs the internet. Check the connection, or a work proxy or firewall, and click Install again. It carries on where it stopped.
  • "Node.js was downloaded but will not run": antivirus probably removed it. Add the app's folder to your antivirus exclusions, or install Node.js yourself from nodejs.org, then click Install again.
  • "The Node.js on this PC (v6...) is too old", npm ERR!, or a file named npm-debug.log in the _system folder: the PC has an old Node.js. From v1.10.81 the app sets up a current one in its own folder by itself. On an older version: install Node.js LTS from nodejs.org, delete the _system ode_modules folder (the _system folder is hidden: in File Explorer, View → Show → Hidden items), and click Install again. Never delete the data folder.
  • "Free GST Billing is already installed on this computer, in: ...": you extracted a new ZIP into a new folder. Your invoices are in the folder it names. Open that copy from your Desktop shortcut and use More options → Update to the latest version; the new folder can be deleted.
  • "The app cannot write to its own folder": it is inside C:Program Files, on a read-only drive, or blocked by antivirus. Move the Free-GST-Billing folder to Documents or D: and open it from there.
  • "Drive ... is almost full": the install needs about 400 MB free. Empty the Recycle Bin or delete old downloads, then try again.
  • "Windows can install Node.js LTS for this PC ... Install Node.js LTS now?": the app could not download Node.js itself, so it offers Windows' own installer. Type Y to accept (Windows may ask for permission), or anything else to install it yourself from the page it opens.

#"Still starting..." or "The server has not answered in 90 seconds"

The first start after an install or update is slow, because antivirus checks every new file. Wait a minute, then open http://localhost:47371 in your browser. If it still does not open, close the black window and click Open App again; from v1.10.81 it also repairs an install that an update left half done. If the window shows an error above that line, the entries under The install stopped with an error say what to do.

#"Cannot connect", a blank page, or "Needs a Quick Start"

The app is not running. Open the Free GST Billing shortcut and click Open App; it starts the app if needed and opens the right address. You never need to type the address yourself; if its usual port is busy, the app picks another and the shortcut follows it.

#The invoice has the wrong tax split

  • Check your own state in Settings.
  • Check the client's state, or their GSTIN, which fills the state in.
  • If goods go to a different state from the client's address, set Place of Supply on the invoice.
  • For a client abroad, set their country: it is then an export, charged as IGST. For an SEZ unit, tick SEZ on the client.

See How GST is worked out.

#No GST is charged at all

The Tax % column is probably turned off under Customize. Turning it off removes GST from the invoice, and your choice carries over to new invoices. Tick it again. Bills of supply and delivery challans never charge GST.

#Something is missing from the PDF

  • Logo, signature or stamp: check it is uploaded and saved in Settings, and ticked under Customize.
  • UPI QR code: needs a UPI ID on the account, a rupee invoice, and UPI QR ticked under Customize.
  • Bank details or PAN: tick Bank details under Customize; the account needs a bank name.
  • Anything on a receipt printer: receipts leave some things out on purpose. See What a receipt leaves out.

#GSTR-1 export says "blocked"

An invoice number is too long or has characters the portal refuses, or an item has a GST rate the portal does not accept. The message names the first one. See Checks before the file is made.

#An update went wrong

Your data folder is never changed by an update, and a backup was saved in Documents\FreeGSTBill Backups before it started. Run the update again, which fixes most problems. If it still fails, download the ZIP and extract it over the app folder by hand.

#It says VAT instead of GST, or the other way round

Change Region in Settings, and check your country in Company Details. Tax names follow the seller's country.

#Reading a bill photo failed

Use a sharp, straight, well-lit JPG or PNG under 8 MB, cropped to the bill. If it still fails, reload the page with Ctrl + F5 and try again, or enter the bill by hand.

#Can I use it on my phone or another computer?

The app runs on the computer it is installed on, and only that computer can open it. It has no user accounts, so it is deliberately not shared over your network, where anyone connected could read your books. (The optional PIN lock locks the screen on this computer only.) To work on another computer, move your data there.

#Does it need the internet?

Only to install and to update. Invoices, reports, GST returns and even reading bills from photos all work offline. Google Drive upload uses the internet too.

#Is my data sent anywhere?

No. There is no account, no tracking and no server of ours. Your data stays in the app's folder unless you choose Google Drive, which copies files into your own Drive.

#Reporting a problem

Use the Report a problem form on GitHub. It asks for the version (Settings, App Updates), your computer, what you did and what you saw, and a screenshot (hide your GSTIN and bank details). If the app does not start, add what node -v and npm -v show in Command Prompt.

Problems are fixed in the Saturday update, and anything urgent, such as the app not opening, straight away. For a new feature use Ask for a feature.
